Дипломный проект от Skillfactory. 
Компания «СКАН» разработала новый API для поиска публикаций о компании (юридическом лице) в средствах массовой информации по ИНН.
Проект представляет собой многостраничный сайт с адаптивной версткой, обеспечивающей корректное отображение на пк и мобильных телефонах.
При его создании были учтены современные технологические требования:
  - Чистая, адаптивная и семантически правильная верстка;
  - Точное соответствие макету (Pixel Perfect);
  - Именование классов по методологии БЭМ;
  - Оптимизация количества медиазапросов для адаптивности;
  - Валидные HTML и CSS;
  - Применение современных технологий Flexbox и CSS Grid;
  - Проект выполнен с соблюдением всех стандартов качества и современного подхода к разработке.
